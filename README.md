#  Heart Disease Prediction using Machine Learning

##  Overview

This project uses Machine Learning techniques to predict the presence of heart disease based on patient health-related information.

The project is implemented using Python and Jupyter Notebook and includes data preprocessing, exploratory data analysis, model training, and prediction.

##  Objectives

- Analyze patient health data
- Perform data preprocessing and cleaning
- Explore relationships between different medical features
- Train a Machine Learning model
- Predict the likelihood of heart disease
- Evaluate the performance of the trained model

##  Dataset

The dataset contains patient-related health information used for heart disease prediction.

The dataset is stored in:

`heart (1).csv`

The project notebook is:

`heat_discese.ipynb`

##  Technologies Used

- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
